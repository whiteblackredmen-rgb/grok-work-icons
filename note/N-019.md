## タイトル
AIとの長い作業は、閉じる前に1枚にまとめさせる。8つの見出しと、そのまま使える指示文

## 本文
話題が変わったら、新しいチャットに切りかえる。AIの上限がすぐ来てしまう人に向けて、Xでそう勧めている人がいました。上限が来るのは、回数より使い方のせいだ、とも書いています。

そのとおりです。ただ、閉じる前に1つだけやることがあります。

この記事を読むと、AIとの長い作業を閉じるときに、中身を1枚に残せるようになります。何日もかけてAIと書類や資料を作った人に向けて書きます。

### 1. 閉じる前に「まとめの1枚」を頼む

長い会話を閉じると、ファイルは残ります。残らないのは、途中の判断です。

なぜその言い方にしたか。何を確かめて、何を確かめていないか。だれの返事を待っているか。

これは会話の中にしかありません。会話を閉じると、探せなくなります。

そこで、閉じる前にAIへ1つ頼みます。「この作業を1枚にまとめて」です。

この研究室では、この1枚を「卒業レポート」と呼んでいます。作業が1つ終わるたびに書かせます。

### 2. 見出しは8つに決めておく

「まとめて」だけだと、AIは感想文のような要約を返します。次に使えません。

見出しを先に決めます。この研究室で使っている見出しは、次の8つです。

1. 何であったか（ゴールと、終わりの形に届いたか）
2. 使った材料と、その置き場
3. 途中で変えた方針と、その理由
4. 出したもの（ファイル名・出した先・日付）
5. 結果（まだなら「未定」と、分かる日）
6. 学び（何をしたら、どうなったか）
7. 次に使えるもの（書類の型・指示文・かかった時間・次に使える場面）
8. 残っている待ち（結果の通知日・相手への約束）

大きく分けると、3つです。やったこと（1〜5）。次に使えるもの（6・7）。残ったこと（8）。

### 3. 指示文をそのまま貼る

次の指示文（AIへの依頼の文章）を、作業の最後に貼ります。

```
この会話の作業を閉じます。閉じる前に、次の8つの見出しで1枚にまとめてください。
1. 何であったか（ゴールと、終わりの形に届いたか）
2. 使った材料と、その置き場
3. 途中で変えた方針と、その理由（私が決めたことは「私の判断」と書く）
4. 出したもの（ファイル名・出した先・日付）
5. 結果（まだなら「未定」と、分かる日）
6. 学び（「何をしたら、どうなったか」の形で）
7. 次に使えるもの（書類の型・指示文・かかった時間・次に使える場面）
8. 残っている待ち（結果の通知日・相手への約束）

決まり：
・この会話に出てきたことだけを書く。推測で埋めない。
・分からないところ、確かめていないところは、行の頭に「❓」を付ける。
・日付は年月日で書く。「昨日」「来週」は使わない。
```

出てきた1枚は、ファイルにして保存します。置き場は、その作業のフォルダです。

### 4. 「学び」は、したことと結果の組で書かせる

学びを「丁寧に確認することが大切」と書かせても、次に使えません。

「何をしたら、どうなったか」の形にします。実際の1枚から、2つ引きます。

- フォルダの中の文書を中身で比べたら、入力前の古い版だと分かった。その前に一度、古い版を見て、誤った確認結果を伝えていた。
- 全部の項目を一覧にした編集用のページを作り、本人が直接直した。チャットの往復なしに、25か所を1回で反映できた。

1つ目は失敗の記録です。次の作業では、最初に「どれが最新か」を確かめられます。

2つ目はうまくいった手順です。このときの項目は、全部で65ありました。同じやり方を、次の書類にも使えます。

### 5. 「次に使えるもの」には、かかった時間も入れる

7番目の見出しが、この1枚のいちばんの値打ちです。

ある応募書類の1枚には、こう書いてありました。「チェック約30分＋修正・編集・送信 約2〜3時間」。

別の申請の1枚には「全体像の整理から提出まで2日」とあります。

かかった時間が分かると、次に似た書類が来たとき、いつ始めればよいかを決められます。

型も書かせます。依頼メールの型。求められている力と自分の実績を並べた、対応表の型。

「次に使える場面」も1行で書かせます。実際の1枚には、次の申請書類に使える、と書いてありました。

### 6. よくある失敗3つと、直し方

**失敗1：あとで書こうとして、書けない。**
その場で記録を残さなかった日がありました。その分は、あとから作業の履歴をたどって書き直すことになりました。

直し方：まとめは、会話を閉じる前に書かせます。日々の小さな区切りでは、4行だけ残します。進んだこと。決めたこと。止まっていること。次の一手（1つ）。

**失敗2：AIが推測で埋める。**
ある1枚には、本人がどう思ったかについて、AIの推測が7点入っていました。本人の確認は、まだでした。

直し方：指示文に「推測で埋めない」「分からないところは❓」と入れます。❓の行だけ、自分で確かめます。

**失敗3：書いた置き場に、ファイルがない。**
1枚を書いた直後に、作業のフォルダの中身が見えなくなったことがありました。置き場が書いてあっても、動かせば探せなくなります。

直し方：閉じる前に、2番目の「置き場」を自分の目で開いて確かめます。

もう1つ、始め方の話です。終わりの形が決まっていない作業は、閉じられません。

作業の最初に、「何がどうなったら終わりか」を1行で決めておきます。決まらないときは、そこに❓を付けて、先に確かめます。

### まとめ

- 長い作業を閉じる前に、AIに「8つの見出しで1枚に」と頼む。
- 学びは「何をしたら、どうなったか」。次に使えるものには、かかった時間も書かせる。
- まず試す1つ：いま開いている長い会話に、3の指示文を貼ってみる。
